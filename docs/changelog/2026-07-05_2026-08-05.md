## 1. Модуль «Цех» (v2.13 – v2.20 + июльские доработки) — крупнейший блок

- Товар-результат с новым SKU, раздельные склады сырья/продукта
- Конвейерный UI Сырьё → Тара → Продукт; многострочные составы
- Ручные затраты на производство; единицы измерения из МойСклад
- Пресеты операций per-department + блок «Шаблоны» в форме
- Копирование операций, панель «Последние операции»
- Пропорциональный пересчёт от блока «Итого продукта»
- Зарплата рабочего по логике приёмки (prodCost)
- Удаление техоперации в МойСклад при удалении операции
- Переименование «Упаковка» → «Цех» (миграция, роуты, UI)

## 2. Дашборды

- Общий дашборд предприятия: сводные таблицы отделов, вкладка «Сырьё»,
  фильтры по отделу/камню/продукту, производство цеха в сводках
- Дашборд мастера: сводка по продуктам в разрезе отделов (v3.5.0)
- Дашборд работника: выработка цеха в сводке и зарплате
- Выработка админа из списка работников

## 3. Отделы и права

- Работник может состоять в нескольких отделах (pivot `department_worker`)
- «Помощник мастера» доступен как мастер/приёмщик в документах
- Итоги: настраиваемая видимость для мастера, сводка только по своему отделу (v3.2.0)
- Отдел документа по создателю операции, запрет пустого отдела (v3.3.0)
- Смена отдела админом на странице приёмки (v3.4.0) и партии
- Партии: обязательный отдел при создании
- Приёмка: выбор отдела в форме, наследование отдела от партии сырья,
  отдел приёмки ведёт отдел партии

## 4. Себестоимость

- Ставка мастера по коэффициенту продукта `masterCostCoeff` + настройки
  себестоимости отдела (v3.6.0)
- Произвольные накладные расходы отдела — таблица `department_expenses`
  вместо глобальных ключей (v3.7.0)
- Расшифровка себестоимости в примечании техоперации (v3.7.1)

## 5. UX и надёжность

- Единая блокировка форм при сохранении — `data-submit-guard`
- Спиннеры и защита от двойной отправки в приёмке
- Цветовая дифференциация шаблонов цеха по типу плитки
- Полная история изменений партии, сортировка по дате изменения
- Нумерация ТО-документов по собственной таблице (уход от коллизий)
- Актуализация остатков `product_stocks` из МойСклад при приёмке (fix)

## Оценка трудозатрат и рыночной стоимости

Оценка сделана 06.08.2026 по объёму и сложности итогового кода
(fullstack PHP/Laravel + Bootstrap/JS + интеграция МойСклад).

### Трудозатраты по блокам

| Блок | Оценка |
|---|---|
| Модуль «Цех» | 7–9 дней |
| Дашборды предприятия и мастера | 3–5 дней |
| Переработка отделов/прав | 4–6 дней |
| Модель себестоимости | 3–4 дня |
| UX и надёжность | 2–3 дня |
| **Итого** | **19–27 человеко-дней (160–180 ч)** |

≈ полный месяц senior-разработчика на фултайме. Треть объёма — тесты.

### Рыночная стоимость (ориентиры РФ, 2026)

| Вариант исполнителя | Стоимость |
|---|---|
| Штатный senior (ЗП 250–400 тыс. ₽ + налоги/взносы) | 350–550 тыс. ₽ |
| Фрилансер (2 500–4 500 ₽/ч × 160–180 ч) | 400–800 тыс. ₽ |
| Студия/агентство (3 500–6 000 ₽/ч + менеджмент) | 600 тыс. – 1,1 млн ₽ |

**Реалистичная середина: ~450–700 тыс. ₽** за эквивалентный результат «под ключ».

Оговорки: оценка не включает постановку задач, ручное тестирование на
реальных данных МойСклад и доработки по фидбэку — на рынке это +15–25%
к бюджету. Календарно работа заняла 13 активных дней — плотнее
«рыночного» темпа; оценка отражает стоимость результата, а не
фактически потраченное время.
