# Товары: как это работает

Справочник товаров — это копия каталога МойСклад: названия, артикулы, группы, цены,
коэффициенты ставок и остатки по складам. Программа ничего не заводит сама — товары создаются
и меняются в МойСклад, а здесь их можно найти, посмотреть остатки и обновить данные.

Эта страница — справка для мастеров и администраторов.

---

## 1. Откуда берутся товары

- Кнопка **«Синхронизировать»** в [списке товаров](app:products) загружает из МойСклад группы
  и все товары. Уже известные товары обновляются, новые добавляются.
- Создать, изменить или удалить товар в программе нельзя — только в МойСклад, затем
  синхронизация.
- Товар, удалённый в МойСклад, из программы при синхронизации не удаляется.
- Группа, которой больше нет в МойСклад, удаляется; её товары остаются «Без группы».
- Кнопка **«Обновить»** в карточке товара (и значок ↻ в строке списка) перечитывает из
  МойСклад один товар: название, артикул, единицу измерения, описание, цены, коэффициенты.
  Остатки этой кнопкой не обновляются — для них есть свои кнопки (см. раздел 4).
- **Артикул** — поле «Артикул» товара в МойСклад, а если оно пустое — «Код».

## 2. Артикул и что по нему видно

Артикул имеет вид `КК-ММ-ФФ`, например `04-01-30`. По нему программа определяет вид товара
и цвет камня.

**Первая часть — категория** (своя иконка в списках и формах):

| Код | Категория |
|---|---|
| 01 | Плитняк (сырьё) |
| 02 | Щебень |
| 03 | Валуны |
| 04 | Плитка из камня |
| 05 | Камень для бани |

**Первые две части — камень.** Карточки и строки красятся в цвет камня (полоса слева и
светлый фон). Сырьё `01-…` и плитка `04-…` из того же камня окрашены одинаково:

| Код | Камень | Цвет |
|---|---|---|
| 01-01 / 04-01 | Кварцит | серый |
| 01-02 / 04-02 | Серицит | персиковый |
| 01-04 / 04-04 | Кора дерева | оранжевый |
| 01-06 / 04-06 | Златолит | жёлтый |
| 01-07 / 04-07 | Сланец зелёный | зелёный |
| 01-08 / 04-08 | Чёрный сланец | чёрный |
| 01-09 / 04-09 | Кварцит чёрный | охра |
| 01-10 / 04-10 | Златолит зелёный | бледно-зелёный |

Остальные товары не окрашиваются.

**Третья часть `30` — мелкая плитка.** В документах такая позиция получает плашку
«Мелкая плитка» (если это правило заведено в отделе). В стандартном наборе правил плашка на
деньги не влияет — это только метка. Подробнее о правилах — в
[Выработка и ставки](pay.md).

## 3. Коэффициенты ставок

У каждого товара два коэффициента — они хранятся в доп. реквизитах товара в МойСклад:

- **prodCostCoeff** — коэффициент пильщика;
- **masterCostCoeff** — коэффициент мастера. Пустой или не заведённый реквизит считается
  нулём — мастер получает базовую ставку отдела.

Чем больше коэффициент, тем дороже единица продукции; при коэффициенте 0 платится базовая
ставка отдела. Как именно коэффициент, ставка отдела и правила складываются в рубли — в
[Выработка и ставки](pay.md); ставки отделов задаются в [Настройках](app:settings).

Где видно и как поменять:

- В карточке товара, в блоке **«Основная информация»**; в его заголовке коэффициенты
  показаны кратко: `коэф. 1,75 / 3`. Лишние нули не выводятся, разделитель — запятая.
- Менять коэффициенты может **только администратор**: форма в том же блоке, кнопка
  **«Сохранить в МойСклад»**. Обязательны оба поля, допустимо от −100 до 100.
- Значения **сначала записываются в МойСклад**. Если МойСклад отказал — в программе ничего не
  меняется, иначе следующая синхронизация вернула бы старое значение.
- Если в МойСклад не заведён реквизит `prodCostCoeff` или `masterCostCoeff`, сохранение
  не пройдёт — программа назовёт недостающий реквизит.
- Новый коэффициент подхватывается при следующем расчёте позиции. Уже сохранённые документы
  сами по себе не пересчитываются.

## 4. Остатки

Остаток хранится **по каждому складу** отдельно.

| Показатель | Что значит |
|---|---|
| **Кол-во** | Остаток на складе по МойСклад. |
| **Резерв** | Зарезервировано под заказы. |
| **В пути** | Ожидается на склад. |
| **Доступно** | Кол-во − резерв. |
| **Общий остаток** | Сумма остатков по всем складам. |

- Товар **«В наличии»**, если общий остаток больше нуля; иначе — «Нет в наличии».
- В карточке показаны только склады, где хоть что-то не равно нулю. Сколько складов с нулями
  скрыто — написано под таблицей.
- Учитываются только склады, известные программе.

Когда остатки обновляются:

- **После документов программы** — приёмки, операции цеха, партии сырья, прихода, заявки в
  производстве: перечитываются остатки тех товаров, которые документ задел.
- **Каждый день в 06:00 (МСК)** — полное обновление всех товаров. Оно ловит движения,
  сделанные прямо в МойСклад.
- **Вручную**: кнопка **«Обновить остатки по складам»** в списке (все товары, может занять
  время) и **«Синхронизировать остатки»** в блоке «Остатки по складам» карточки (один товар).

Правила обновления:

- Склад, где в МойСклад остаток стал нулевым, обнуляется и в программе.
- Если МойСклад не ответил или ответил пустотой, прежние остатки не стираются.

## 5. Список товаров: поиск и фильтры

- **Поиск** — по названию, артикулу и описанию, без учёта регистра. Достаточно части слова.
- **Группа товаров** — выбранная группа **вместе со всеми вложенными** подгруппами.
- **Наличие** — «Все», «В наличии», «Нет в наличии».
- На странице 15 товаров. Щелчок по заголовку колонки «Название», «Артикул» или «Цена»
  сортирует список по этой колонке.
- Плитка **«Группы»** открывает дерево групп с кнопкой синхронизации только групп.

## 6. Выбор товара в формах

В приёмке, цехе, партиях сырья, приходе и фильтрах товар выбирается одним и тем же полем.

- Набирайте начала слов названия в любом порядке: `плит квар 50` найдёт
  «Плитка из Кварцит 50хL». Показываются первые 15 совпадений.
- Кнопка **«Выбрать из каталога»** открывает дерево групп с поиском по каталогу.
- В некоторых формах рядом с товаром видны остатки: общий и на складе-источнике. Зелёный —
  остаток есть, красный — нет.
- В приёмке по партии сырья список плитки сужается до того же камня: для сырья `01-01`
  предлагается плитка `04-01-…`. Галочка **«весь каталог»** снимает это ограничение.
- Каталог для выбора обновляется не чаще раза в 10 минут. После синхронизации, обновления
  товара или смены коэффициентов он сбрасывается сразу; уже открытую форму нужно
  перезагрузить.

| 4. Остатки | `Moysklad\StockSyncService::applyRows`, `syncAllProductsStocksByStores`, `updateProductStocksByMoyskladId`, `refreshProducts`; команда `moysklad:sync-stocks` в `routes/console.php`; `Product::getTotalQuantityAttribute`, `getInStockAttribute` | `Stock/ProductStockTest`, `Moysklad/StockSyncServiceTest`, `Moysklad/StockSyncByStoreTest` |

Заметки:

- Остатки — только `product_stocks`; колонка `products.quantity` удалена миграцией

- `applyRows` пишет пачкой через `upsert` в обход событий модели, поэтому `available` считается
  там же, а не хуком `ProductStock::saving`.
- Все маршруты раздела — под `can:see-products`; запись коэффициентов дополнительно под
